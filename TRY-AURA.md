# Try Aura

This is the first test build of the product your company intends to offer to individuals and businesses. Test it as a customer would: describe an outcome in ordinary language and judge whether the result is useful and easy to understand.

Double-click **Aura** on your Desktop. The complete project is in **Desktop\Aura**.

## A first trial

1. Type: “Help me plan tomorrow. I have two hours to study and a meeting at three.” Judge whether the response is useful and natural.
2. Press the microphone, speak a request, and stop recording. Review the transcript and send it. Enable spoken replies to hear Aura answer.
3. Ask: “Check my computer's memory and explain what you find in simple language.” Compare its explanation with the tool result.
4. Select a folder containing a sample text or Markdown document. Ask Aura to list the files and summarize that document.
5. Ask: “Create a note with a checklist for testing my new assistant.” Review the proposed write and approve it. Check the resulting file in Documents\Aura.
6. Try stopping a task with Escape. Try the warm, professional, and direct personality settings under Aura intelligence.

## What to judge

- Did Aura understand what you wanted without technical instructions?
- Was the answer correct, useful, and easy to understand?
- Did the voice sound natural, and was the transcript accurate?
- Was the wait acceptable?
- Did it explain missing capabilities or failures honestly?

When something disappoints you, report what you asked, what happened, and what you expected. You do not need to diagnose the software. Never include API keys in feedback.

## Current boundaries

This build supports conversation, push-to-talk speech, selected-folder listing, supported text-file reading, computer information, and creating new Markdown notes. It does not yet operate arbitrary applications, browse websites, send email, install software, or provide organization accounts. Voice is turn-based, not a continuous interruptible call. Conversations and task history currently last for the session.

Your selected context is sent to the configured AI services to answer requests. Provider credentials are encrypted locally and are not part of the source project. This local test build is not yet a service to distribute to paying customers.
